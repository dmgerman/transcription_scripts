#+title: Transcription
#+author: dmg

* Overview

Transcribes audio recordings with speaker separation (diarization).
Pipeline: WhisperX (transcription + word-level alignment) → pyannote (speaker diarization).

Handles any number of speakers: pyannote determines how many are present, so a
solo voice memo and a group conversation both work without being told in
advance. Use =--min-speakers= / =--max-speakers= only to constrain the guess.

The language is auto-detected per file — English, Spanish and Japanese
recordings can sit in the same directory. Pin it with =--language= when you
already know it, which skips a few seconds of detection per file.

* Requirements

- Python 3.13 (via =.venv=, set up automatically — see Setup)
- FFmpeg (=brew install ffmpeg=)
- GPG (for reading the HuggingFace token from =~/.authinfo.gpg=)
- A HuggingFace account with access granted to three gated models (see below)

* Setup

#+begin_src bash
cd ~/git.dmg/transcription_scripts

# Installs ffmpeg/gnupg, creates .venv, installs dependencies, checks the token
./requirements.sh
#+end_src

Accept the following HuggingFace model agreements (free account required):
- https://huggingface.co/pyannote/speaker-diarization-3.1
- https://huggingface.co/pyannote/segmentation-3.0
- https://huggingface.co/pyannote/speaker-diarization-community-1

Add your HuggingFace token to =~/.authinfo.gpg=:
#+begin_src
machine huggingface.co login <user> password <token>
#+end_src

* Usage

#+begin_src bash
# Transcribe a single file (output alongside input)
~/git.dmg/transcription_scripts/transcribe.py recording.WAV

# Transcribe to a specific output directory
~/git.dmg/transcription_scripts/transcribe.py recording.WAV --output-dir /tmp

# Transcribe multiple files
~/git.dmg/transcription_scripts/transcribe.py *.WAV --output-dir ~/transcripts
#+end_src

Output is a =.md= file per audio file with speaker-labeled turns, one block per
speaker regardless of how many there are:

#+begin_example
**SPEAKER_00**: Entonces, vamos, ¿les puedo preguntar?

**SPEAKER_01**: Sí, sí, estoy de acuerdo.

**SPEAKER_02**: Yo también.
#+end_example

A single-speaker recording simply yields one =**SPEAKER_00**= block.

Files with an existing transcript are skipped automatically.

* Options

| Flag                | Default        | Description                                        |
|---------------------+----------------+----------------------------------------------------|
| =--model=           | =large-v2=     | Whisper model size                                 |
| =--device=          | =cpu=          | =cpu= or =cuda= (ASR; ctranslate2 has no MPS path) |
| =--diarize-device=  | =mps= if avail | Device for diarization; falls back to cpu          |
| =--compute-type=    | =int8=         | =int8=, =float16= or =float32=                     |
| =--threads=         | cores − 2      | CPU threads for ASR                                |
| =--language=        | auto-detect    | Language code, e.g. =en=, =es=, =ja=               |
| =--batch-size=      | =8=            | ASR batch size; lower it to cut peak memory        |
| =--min-speakers=    | auto           | Lower bound on speaker count                       |
| =--max-speakers=    | auto           | Upper bound on speaker count                       |
| =--no-diarize=      | off            | Skip diarization; output loses speaker labels      |
| =--output-dir=      | (same dir)     | Where to write =.md= files                         |
| =--checkpoint-dir=  | =/tmp/transcribe= | Where stage checkpoints are written             |
| =--force=           | off            | Ignore existing checkpoints                        |
| =--overwrite=       | off            | Replace existing =.md= output                      |

* Notes

- Model weights are cached in =~/.cache/huggingface/hub/= (5.3 GB, of which
  2.9 GB is =large-v2=) and =~/.cache/torch/= after the first run — subsequent
  runs are faster.
- ASR and alignment run on the CPU; only diarization uses the Apple GPU.
  ctranslate2 (the Whisper backend) has no MPS support, so =--device= stays
  =cpu= on a Mac.
- Measured on one minute of audio on an M2 (12 cores), full diarization:

  | Configuration                              | Wall time |
  |--------------------------------------------+-----------|
  | float32, 4 threads, cpu diarization        | 86.8 s    |
  | int8, 10 threads, cpu diarization          | 73.6 s    |
  | int8, 10 threads, =mps= diarization        | 41.4 s    |

  Diarization alone drops from 37.8 s to 9.5 s on =mps=, with identical
  segments and speakers. Transcript text is unchanged across all three.
- Peak memory for =large-v2=: 8.55 GB at =--compute-type float32=, 5.01 GB at
  =int8= (60 s clip, =--batch-size 8=). Longer files and diarization push this
  higher; lower =--batch-size= if the machine starts swapping.
- Whisper hallucinates confident text when fed silence — a 25-second silent
  recording produced Chinese boilerplate (=谢谢大家=) with no speaker assigned.
  =dji_copy.sh= therefore skips recordings shorter than 30 seconds.
- Stage checkpoints (ASR, alignment) are written to =/tmp/transcribe= so an
  interrupted run resumes instead of repeating work. Checkpoint names do not
  encode the settings, so pass =--force= after changing =--model= or
  =--compute-type= to avoid reusing a stale checkpoint.
- FFmpeg 8 triggers a harmless torchcodec warning at startup — ignore it.
